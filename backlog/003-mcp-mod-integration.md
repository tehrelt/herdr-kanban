# EPIC-003 — Интеграция MCP в Kanban-мод и запуск агентов

**Status:** [ ] TODO

**Priority:** P1

## Цель

Интегрировать поддержку MCP в интерфейс мода `mods/kanban` и сценарии запуска AI-агентов, чтобы пользователи могли подключать MCP-сервер бэклога в проекте в один клик, а запускаемые агенты работали с задачами через MCP.

## Задачи

- [ ] TASK-003.1 Реализовать обнаружение и безопасную генерацию `.mcp.json` в корне проекта
  - Проверять наличие конфигурации `herdr-kanban` в `.mcp.json` для активного `projectRoot`
  - Добавлять или обновлять запись сервера без затирания существующих MCP-серверов пользователя
- [ ] TASK-003.2 Добавить UI-управление MCP-интеграцией в `mods/kanban`
  - Отображать статус MCP-подключения в тулбаре или панели настроек (подключён / не настроен / недоступен в read-only SSH)
  - Добавить модальное окно или поповер настройки MCP с кнопкой записи `.mcp.json`, копированием CLI-команды (`claude mcp add`) и JSON-конфига
- [ ] TASK-003.3 Адаптировать промпты запуска агентов под работу через MCP
  - Обновить `buildAgentPrompt` и `buildCreateEpicsPrompt` в `mods/kanban/parser.js` для использования MCP tools при активной интеграции
  - Сохранить fallback-инструкции по прямому редактированию `.md` для проектов без настроенного MCP
- [ ] TASK-003.4 Проверить синхронизацию доски при изменениях через MCP и добавить тесты
  - Убедиться, что `watchFolder` в `mods/kanban/main.js` корректно обновляет доску после вызовов MCP tools
  - Добавить unit-тесты генерации `.mcp.json` и MCP-вариантов промптов в `tests/`

## Definition of Done

- Из интерфейса Kanban можно проверить статус MCP-интеграции и настроить `.mcp.json` или скопировать конфиг для агента.
- Промпты запуска агентов учитывают наличие MCP-конфигурации и сохраняют обратную совместимость.
- `bun test` и `herdr-app check ~/.config/herdr-app/mods/kanban` проходят без ошибок.
