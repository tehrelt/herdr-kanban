# Руководство по использованию Kanban

Эта папка содержит Markdown-бэклог проекта для доски **Kanban** в Herdr.

## 1. Структура папки и именование файлов

- Доска автоматически ищет папки `backlog/`, `docs/backlog/` или `.backlog/` в активном `space` (в `cwd` терминала или корне git-репозитория).
- Каждый эпик хранится в отдельном `.md` файле вида `001-bootstrap.md`, `002-auth.md` или `EPIC-001.md`.
- Служебные файлы (`README.md`, `CURRENT.md`, `CHANGELOG.md`, `AGENTS.md`, `RECIPE.md`, `CONTRIBUTING.md`, `CLAUDE.md`, `LICENSE.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `ARCHITECTURE.md`) доской игнорируются и не отображаются как карточки.

## 2. Формат файла эпика

```markdown
# EPIC-001 — Название эпика

> Проект: **MyProject**

**Status:** [ ] TODO

**Priority:** P1

## Цель

Краткое описание цели эпика.

## Задачи

- [ ] TASK-001.1 Первая задача
  - Подпункт или уточнение
- [-] TASK-001.2 Задача в работе
- [!] TASK-001.3 Заблокированная задача
- [x] TASK-001.4 Выполненная задача

## Definition of Done

- Критерий готовности 1.
- Критерий готовности 2.

## Итог реализации

Краткий итог после завершения.

---
```

### Статусы и приоритеты

- **Статусы:** `[ ] TODO`, `[-] IN PROGRESS`, `[!] BLOCKED`, `[x] DONE`.
- Если строка `**Status:**` отсутствует, статус эпика выводится автоматически по задачам: есть `[!]` → `BLOCKED`, есть `[-]` или смесь `[x]`/`[ ]` → `IN PROGRESS`, все `[x]` → `DONE`, иначе `TODO`.
- **Приоритеты:** `P0` (критический), `P1` (высокий), `P2` (средний), `P3` (низкий).
- **Распознаваемые заголовки секций:**
  - Цель: `## Цель`, `## Goal`, `## Описание`, `## Overview`
  - Задачи: `## Задачи`, `## Tasks`, `## Checklist`
  - DoD: `## Definition of Done`, `## DoD`, `## Критерии готовности`
  - Итог: `## Итог реализации`, `## Прогресс`, `## Summary`, `## Notes`, `## Результат`
- Дополнительные `# H1` секции после разделителя `---` парсером не читаются.

## 3. Работа с доской в Herdr

- **Режимы:** `Эпики` (карточки эпиков с прогресс-баром) и `Задачи` (плоская доска по всем `TASK-*`).
- **Фильтры и поиск:** фильтр по приоритету (`Все`, `P0`–`P3`) и строка поиска по ID, заголовкам, целям и задачам.
- **Перемещение карточек:** перетаскивание между колонками, кнопки `←` / `→` / `✓` при наведении или контекстное меню по правому клику.
- **Панель деталей:** клик по карточке открывает детали эпика — смену статуса и приоритета, переключение чекбоксов задач, добавление новых задач (`Добавить задачу…`), просмотр `Цель`, `Definition of Done`, `Итог реализации` и копирование пути к `.md`.
- **Создание эпика:** кнопка `+ Эпик` в тулбаре или клавиша `n`.
- **Живое обновление:** локальная папка отслеживается автоматически (`watchFolder` + опрос раз в 10 секунд). Удалённые SSH `space` открываются в режиме «Только чтение».

### Горячие клавиши

- `1` / `2` — переключение режимов `Эпики` / `Задачи`
- `/` — фокус в поиск
- `n` — создать новый эпик
- `r` — обновить доску
- `Esc` — закрыть контекстное меню / панель деталей / оверлей

## 4. Запуск AI-агентов и совместная работа

- Кнопка `▶` (или `Запустить <Agent>` в деталях) открывает новую вкладку с выбранным агентом в корне проекта и передаёт промпт с целью, задачами, DoD и путём к `.md` файлу.
- Кнопка `В терминал` отправляет промпт в живой терминал активного `space`.
- Доска использует безопасную запись с проверкой исходного содержимого файла и сохранением `CRLF`/`LF`, поэтому не затирает правки, сделанные агентом на диске.
- **Для агентов:** при работе над задачей обновляйте её чекбокс (`[ ]` → `[-]` → `[x]` или `[!]`), синхронизируйте `**Status:**` эпика и фиксируйте результат в `## Итог реализации`.
