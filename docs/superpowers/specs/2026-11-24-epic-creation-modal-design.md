# Модальное окно создания эпика (вручную и с агентом)

## Цель

Заменить встроенную панель `renderNewEpicBar` на модальное окно с двумя режимами создания эпиков: ручным и с помощью AI-агента.

## Границы

- **Входит:**
  - Модальное окно по центру экрана (по паттерну `renderRemoteFolderPicker`), открывается по `+ Эпик`, `Создать первый эпик` и клавише `n`.
  - Переключатель режимов: `Вручную` и `С агентом`.
  - Режим `Вручную`: приоритет (`P0`–`P3`), название эпика, необязательная первая задача, кнопки `Создать` и `Отмена`.
  - Режим `С агентом`: одно большое поле `Textarea` (`TextareaState` из `gpui-base`) для описания одной или нескольких задач и кнопка `Создать задачи` со встроенным выбором агента (как в `detail.js`, с сохранением в `STORAGE_AGENT`).
  - Генерация промпта `buildCreateEpicsPrompt` в `mods/kanban/parser.js` (описание пользователя, `backlogDir`, следующий номер `EPIC-NNN`, проект, формат `.md` файла) и запуск выбранного агента в новой вкладке (`tab.new`) в корне проекта. Если агент не найден — копирование промпта в буфер обмена.
  - Юнит-тесты для `buildCreateEpicsPrompt` в `tests/parser.test.js`.
- **Не входит:**
  - Отправка промпта в существующий терминал (`hc send`) или фоновый запуск через `exec`.
  - Изменение формата `.md` файлов эпиков.

## Подходы

1. **Подход A (выбран):** запуск выбранного агента в новой вкладке (`tab.new`) с промптом на создание `.md` файлов в `backlogDir`. Работает предсказуемо, показывает прогресс агента, доска обновляется автоматически через `watchFolder`.
2. **Подход B (отклонён):** отправка в живой терминал (`hc send`) — может отправить промпт в обычный shell вместо агента.
3. **Подход C (отклонён):** фоновый `exec` — разные неинтерактивные флаги у CLI-агентов и нет видимого прогресса.

## Затрагиваемые файлы

- `tests/parser.test.js` — тесты `buildCreateEpicsPrompt`
